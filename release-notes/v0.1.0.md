# MCPulse-RAG v0.1.0

Initial public release of `MCPulse-RAG`.

## Added

- Unified top-level `docker-compose.yml` for `qdrant`, `knowledge-mcp`, and `ragcheck`
- Root `.env.example` for configurable knowledge-base mount paths
- Example environment files for both services
- Public-facing `README.md` and `README_CN.md`
- MIT license, version file, and changelog

## Notes

- This release establishes the public project structure for NAS and Docker deployments
- The core service logic remains close to the original private deployment baseline
